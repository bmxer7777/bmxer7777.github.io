## Adding a project

1. Give the project's repo a GitHub Pages site. It then appears at `bmxer7777.github.io/<repo-name>/`.
2. Save a 14:9 screenshot as `assets/thumb-<name>.jpg`.
3. Copy one of the `<article class="project">` blocks in `index.html` and edit the text and links.

## LYRIQ Tracker (archived)

The first version of the tracker. It followed ERAU's Cadillac LYRIQ from CARB testing in Riverside, CA back to Daytona Beach in February 2026. `lyriq/` holds the page, the recorded `location_history.json`, and the original Mac scripts (`extract_location.py`, `tracker_daemon.py`). Its replacement is [ecocar-vehicle-tracker](https://github.com/bmxer7777/ecocar-vehicle-tracker).
